# 44維度特徵向量計算說明 (44-Dimensional Strategic Feature Vector)

本文件詳細說明 MsPacman RL 代理人所使用的 44 維度策略特徵向量（Strategic Feature Vector）的計算方式與各維度代表的物理意義。特徵向量提取實作於 [model.py](file:///Users/Shared/西洋棋代理人/rl_starter_12/model.py#L1009) 的 `extract_strategic_features` 函數中。

---

## 特徵向量設計原則
- **歸一化 (Normalization)**：所有特徵值皆縮放到 `[0, 1]` 或 `[-1, 1]` 區間，以利於神經網路收斂。
- **指數距離衰減 (Exponential Distance Decay)**：對於地圖距離 $d$，使用 $e^{-0.05 \times d}$ 進行縮放。當距離為 0 時，特徵值為 1.0；當距離為 $\infty$ 時，特徵值趨近於 0.0。此設計能讓代理人對「極度靠近」的威脅或目標產生極高敏感度，對「遙遠」的實體逐漸降低敏感度。
- **動態圖特徵 (Graph-based Features)**：基於 Dijkstra 最短路徑演算法計算 Pac-Man 到各個目標（鬼魂、豆子、能量球、水果）在迷宮連通圖上的真實路徑距離。

## 關鍵輔助函數說明
1. **地圖對齊 (`align_coordinates_to_graph`)**：
   由於 Atari 原始 RAM 中的 Pac-Man 座標有些微偏移或不落在圖節點上，計算前會先將其座標對齊至拓撲圖中最接近的合法節點，再進行路徑搜尋。
2. **Dijkstra 最短路徑 (`dijkstra_distance_map`)**：
   根據關卡拓撲圖（隨玩家移動動態建立或預建），以鬼魂/目標為起點向外搜尋，建立整張圖的最短路徑距離字典，以保證距離計算符合真實走法而不是直線（曼哈頓）距離。
