# 小精靈小姐 Ms. Pac-Man (Atari 2600) 128 位元組 RAM 映射表

本文件詳細記錄了 Atari 2600 版本 **《小精靈小姐》（Ms. Pac-Man）** 的 128 位元組 RAM（零頁記憶體位址 `$80` 至 `$FF`）的配置與含義。此映射表常被街機學習環境（Arcade Learning Environment, ALE）以及 Gym/Gymnasium 環境（`MsPacman-ram-v5`）所採用。

---

## Atari 2600 記憶體架構概述

Atari 2600 主機內建於 MOS 6532 RIOT（RAM、I/O、定時器）晶片中的 **RAM 剛好只有 128 位元組**。在 6507 CPU 的定址空間中，這段 RAM 被映射到 **`$80` 至 `$FF`**（同時作為零頁（Zero-page）與堆疊區（Stack area）使用）。
由於該主機沒有作業系統，也沒有專用的視訊記憶體（Video RAM），因此這 128 位元組必須儲存所有的遊戲變數、分數、定時器、角色位置、堆疊操作以及迷宮配置。

## 強化學習（AtariARI）關鍵動態註解

為強化學習 Agent 提取特徵（Features）時，請參考以下索引：

* **玩家座標：** `obs[10]` (X), `obs[16]` (Y)
* **水果座標：** `obs[11]` (X), `obs[17]` (Y) — *重要：只有當水果出現在畫面上時，這些數值才不為 0。*
* **鬼魂座標 (X, Y)：**
  * **Sue（橘色）：** `obs[6]`, `obs[12]`
  * **Inky（青色）：** `obs[7]`, `obs[13]`
  * **Pinky（粉色）：** `obs[8]`, `obs[14]`
  * **Blinky（紅色）：** `obs[9]`, `obs[15]`
* **可食用（藍色）鬼魂定時器：** `obs[116]`
* **分數計數器：** `obs[120]`
* **生命值計數器：** `obs[123] & 0x0F`
* **關卡索引：** `obs[123] >> 4`
